# BAB dashboards

Demo dashboards for BAB. All data is sample data. They are static pages with pre-computed sample content: open the link, no login.

## Coach dashboards

| Sport | Link |
|---|---|
| Football | https://ilaria18.github.io/dashboard/ |
| Volleyball | https://ilaria18.github.io/dashboard/volleyball/ |
| Athletics | https://ilaria18.github.io/dashboard/athletics/ |

## Medical staff dashboards

| Sport | Link | Direct to the athlete file |
|---|---|---|
| Football | https://ilaria18.github.io/dashboard/football/medical/ | https://ilaria18.github.io/dashboard/football/medical/#ath |
| Volleyball | https://ilaria18.github.io/dashboard/volleyball/medical/ | https://ilaria18.github.io/dashboard/volleyball/medical/#ath |

Medical pages: Overview, Athletes to assess, Athlete file, Areas and load, Knee and ACL (football only), Hormonal health, Weight and height, Feedback (a form to write to the BAB team), Calendar.

Athletics has no medical staff dashboard.

## Older version

`index1.html` is the first medical demo ("BAB Staff Dashboard"). It is kept for reference and is not updated.

## Notes

- If a page looks old after an update, reload without cache (Cmd+Shift+R or Ctrl+Shift+R) or add `?v=2` to the address.
- Medical dashboards read only data the athlete agreed to share with the medical staff. Names and health data shown here are invented.
